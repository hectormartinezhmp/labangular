Crea un nuevo proyecto

SPrimeros pasos con la herramienta
Config

Usa ng new para generar la estructura completa del proyecto. Angular te hará algunas preguntas sobre la configuración.

terminal 
ng new mi-primera-app
  
  # ¿Añadir Angular routing? → Yes
  # ¿Qué formato de estilos? → CSS (o SCSS)

Esto genera la siguiente estructura de carpetas:

mi-primera-app/
├── src/
│ ├── app/
│ │ ├── app.ts
│ │ ├── app.html
│ │ ├── app.css
│ │ └── app.routes.ts
│ ├── index.html
│ └── main.ts
├── angular.json
├── package.json
└── tsconfig.json
