instalación Node.js y npm

Preparación del equipo de trabajo
Setup

Angular necesita Node.js 18.13 o superior. Puedes descargarlo desde el sitio oficial e instalarlo con el ejecutable .msi. npm se instala automáticamente junto con Node.

Además es recomendable utilizar Visual studio code para la creación de la web, puedes descargarlo desde el sitio oficial.

💡

Es recomendable usar nvm (Node Version Manager V10 o superior) para gestionar múltiples versiones de Node sin conflictos entre proyectos.

Verifica que la instalación fue exitosa ejecutando estos comandos en la terminal de VScode que te mostrarán las versiones:

terminal 
node -v
npm -v
