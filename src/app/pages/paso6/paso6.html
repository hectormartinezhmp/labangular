Genera un nuevo componente

Arquitectura basada en componentes
Código

Angular CLI genera componentes automáticamente con todos los archivos necesarios. Usa el comando ng generate:

terminal 
ng generate component header

Esto crea la carpeta src/app/header/ con los 4 archivos del componente. Úsalo en tu app añadiéndolo al template del componente padre:

app.html 
<app-header></app-header>
  <main>
    <!-- contenido principal -->
  </main>
⚠️

En Angular 17+ con standalone components, necesitas importar el componente en el array imports: [] del componente padre donde lo vayas a usar.

app.routes.ts 
 export const routes: Routes = [
        {{ac}}path: '', component: Header{{cc}},
