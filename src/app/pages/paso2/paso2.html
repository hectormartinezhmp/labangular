Instalación Angular CLI

Pilar base para el uso del framework
Setup

Angular CLI es la navaja suiza de Angular. Te permite crear proyectos, generar componentes, ejecutar pruebas y compilar la app. Para instalarla ejecuta el siguiente comando:

terminal 
npm install -g @angular/cli

Confirma la instalación con:

terminal 
ng version
