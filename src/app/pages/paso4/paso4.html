Ejecuta el servidor de desarrollo

Hola Mundo del framework
Dev

Navega dentro de la carpeta del proyecto y arranca el servidor local. Angular incluye live reload — lo que significa que los cambios en el código se verán reflejados en cuanto guardes el fichero.

terminal 
cd mi-primera-app
  ng serve --open
  # Abre automáticamente http://localhost:4200
🚀

Si el puerto 4200 está ocupado, puedes cambiar el puerto por defecto usando: ng serve --port 4300
