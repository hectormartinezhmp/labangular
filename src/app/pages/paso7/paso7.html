Deploy

Cuando tu app esté lista, genera el build de producción. Angular optimizará, minificará y compilará el código de TypeScript a JavaScript estándar.

terminal 
ng build
  # Los archivos finales se generan en: dist/mi-primera-app/

Sube el contenido de la carpeta dist/ a cualquier hosting estático: Vercel, Netlify, GitHub Pages o Firebase Hosting.

🌐

Para despliegue en GitHub Pages usa el paquete angular-cli-ghpages con un solo comando: ng deploy.

terminal 
npm install -g angular-cli-ghpages
  ng deploy --base-href=/nombre-del-repo/
